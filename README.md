## Snake Game

## Description
This project is a **Snake Game**.
In this competition, the user helps the hungry snake to reach its food by using the arrow keys on the keyboard.
More food equals more points.

## How to run
run following:
```bash
python -m venv env
. env/bin/activate
pip install -r requirements.txt
python main.py
```

## How to deploy

You need to have docker installed on your machine. you can easily deploy the service with executing
the following command in your terminal:

```bash
docker compose up
```
